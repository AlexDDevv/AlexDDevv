## Projet à la une

### 📖 Nuit d'Encre, projet démo *(terminé)*

Plateforme sociale de bibliothèque en ligne : gestion de lectures, critiques, recommandations, gamification et fil d'activité. Architecture monorepo (pnpm workspaces), déployée en Docker Compose avec CI GitHub Actions (lint, typecheck, tests Jest/Vitest). Projet clos, gardé en ligne comme vitrine technique pour mes entretiens.

**Frontend :** React 19, TypeScript, React Router v7, Apollo Client, Tailwind CSS 4, Radix UI
**Backend :** Apollo Server, TypeGraphQL, TypeORM, PostgreSQL, JWT + OAuth Google, DataLoader
